# twiki

Publish Obsidian notes to Cloudflare or a static site. Keep your Markdown, wikilinks and attachments in a vault you own.

Start with [[getting-started/index|Getting started]]. Find command details in [[reference/cli|CLI reference]] and settings in [[reference/configuration|Configuration reference]].

- [[guides/index|Guides]] — authoring, hosting, authentication and caching.
- [[examples/index|Examples]] — runnable configurations and connected notes.
- [[reference/index|Reference]] — commands, settings, releases and troubleshooting.

This documentation is itself a Twiki vault. The CLI reference is generated from Commander command definitions; the configuration reference and editor schema come from the same schema used to validate your configuration. CI checks generated files and exercises the examples before deployment.
