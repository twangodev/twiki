# twiki

Publish Obsidian notes to Cloudflare or a static site.

```sh
bun add --exact @twango/twiki
bunx twiki init
bunx twiki dev
```

Build with `bunx twiki build --target cloudflare` or `bunx twiki build --target static`.

This site is a plain folder published with twiki. Explore [[topics/first-note|a connected note]], math $x^2$, and the knowledge graph.
