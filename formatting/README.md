# formatting/

Specs for content types shared across courses. Read the relevant spec before
filing or writing content.

- [[course-readme]] — the course root `README.md` (its Map of Content)
- [[lecture]] — lecture notes
- [[exam]] — `exams/` structure and review material
- [[assignment]] — homework, projects (`p<N>`), activities (`a<N>`)
- [[conversion]] — turning binaries into markdown

These specs govern structure, linking, and the parts that should feel
identical across courses. Courses keep their own naming/numbering schemes,
but restructuring content to match these specs is always allowed — final
output quality wins over preserving what's there.

Per-directory `assets/` is the default home for figures everywhere; a
course-level `assets/` is only for files genuinely shared across notes.
