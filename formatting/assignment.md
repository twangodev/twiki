# Assignments

Covers homework (`homework/` or `hw<N>/`), projects (`p<N>/`), and activities
(`a<N>/`). Keep the course's existing numbering and padding.

## Directory-style assignments (projects, activities)

```
p05/
├── README.md     # the converted spec — the assignment's primary doc
├── assets/       # its figures: <doc>-figNN.jpg, never hashes
└── (code, as the course requires)
```

- `README.md` is the converted assignment spec, faithful to the original.
- Student work product (notes, solutions, retrospectives) goes in separate
  files (`notes.md`, `solution-notes.md`) — never edited into the spec.

## File-style homework

Single files (`homework/hw3.md`) when there's no code: the converted handout,
with the student's solution either below a `## Solution` heading or in a
sibling `hw3-solution.md` — follow the course's existing pattern.

## Linking

Link each assignment to the lectures it draws on, and from the course README.
